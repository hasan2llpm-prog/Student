# خطة Student Web Preview

## نطاق المرحلة الأولى

نبدأ بمعاينة ويب متجاوبة مرتبطة بصريًا بهوية Student الحالية، ثم نربطها بنفس مشروع Supabase الحي المستخدم في Android. لا يوجد نقل لكلمات المرور أو إنشاء حسابات ثانية: Supabase Auth يبقى مصدر الحسابات الوحيد، وتُقرأ الملفات الشخصية والمنشورات والقصص والمحادثات والمحفظة والمفردات والمهام من نفس الجداول والصلاحيات. التنفيذ يكون على مراحل قابلة للتحقق، مع إبقاء بيانات المعاينة كاحتياط فقط عندما لا تكون إعدادات Supabase متاحة.

## خطة النقل الفعلية

1. **الحسابات والجلسات:** تسجيل الدخول بالبريد/كلمة المرور وGoogle عبر Supabase Auth، استعادة الجلسة، تسجيل الخروج، وعرض ملف `profiles` نفسه. لا تُخزّن كلمات المرور في الموقع ولا تُنسخ إلى قاعدة أخرى.
2. **الخلاصة والقصص:** استبدال بيانات المعاينة بقراءة `posts`, `profiles`, `post_likes`, `comments`, `student_stories_v281` و`student_story_views_v281` مع إبقاء RLS مصدر الصلاحيات، ثم إضافة الإنشاء والتعليق والإعجاب ورفع القصص إلى Storage.
3. **التواصل:** نقل `messages`/RPCs والمحادثات اللحظية، الإشعارات، Reels، والملفات الشخصية العامة.
4. **التعلم والذكاء الاصطناعي:** ربط `english_vocabulary`, `student_vocabulary_assignment_v210`, تقدم التعلم، الترجمة، وEdge Function `student-ai` دون كشف مفاتيح المزود.
5. **المتجر والإدارة:** ربط المنتجات والمهام والمحفظة عبر RPCs الحالية، ثم نقل لوحة الإدارة مع فحص الدور من `profiles`/`admin_users` وعدم منح صلاحيات من الواجهة.

لن تُجرى أي عملية حذف أو تعديل مخطط أو نقل بيانات مباشر. كل عمليات الكتابة ستستخدم جلسة المستخدم وRLS أو الدوال الحالية، وكل مرحلة تُبنى وتُراجع قبل نشرها.

## التصميم

ثلاثة اتجاهات أولية واحتمالاتها: **Editorial learning desk** (0.07)، **Soft glass social** (0.06)، **Quiet campus utility** (0.04). الاتجاه المختار هو **Editorial learning desk**.

- **الحركة التصميمية:** مجلة تعليمية رقمية هادئة تلتقي مع كثافة الخلاصة الاجتماعية؛ مساحة واسعة، بطاقات تحريرية، وحواف دقيقة بدل الزخرفة الثقيلة.
- **المبادئ:** وضوح بصري أولًا، تباين مريح، كثافة معلومات محسوبة، وتفاعل سريع لا يغطي المحتوى.
- **فلسفة الألوان:** أزرق Student عميق للثقة، أخضر نعناعي للتقدم والنجاح، كهرماني محدود للتنبيه، وخلفيات عاجية/فحمية حتى تبقى الصور والمفردات هي البطل. لا يُستخدم البنفسجي كلون أساسي.
- **نمط التخطيط:** عمود محتوى مركزي مع rail جانبي يتسع على الشاشات الكبيرة، ويتحول إلى شريط تنقل سفلي على الهاتف؛ لا توجد لوحة مركزية جامدة واحدة.
- **العناصر المميزة:** حلقة قصة متدرجة، شريط تقدم كهرماني رفيع، وبطاقات ذات شريط علوي صغير يعرّف نوع المحتوى.
- **التفاعل:** النقر يغيّر الحالة فورًا، الضغط المطول على القصة يوقفها ويخفي عناصرها، والسحب/التنقل يحافظ على السياق بدل فتح صفحات كثيرة.
- **الحركة:** انتقالات قصيرة 180–240ms، وظهور تدريجي للبطاقات، دون حركات مستمرة تستهلك الانتباه.
- **الخطوط:** Inter للإنجليزية وNoto Sans Arabic كبديل عربي عبر CSS؛ عناوين واضحة، نصوص عملية، وتسميات صغيرة عالية التباين.
- **جوهر العلامة:** Student مساحة واحدة يتعلم فيها الطالب ويتواصل ويتابع تقدمه؛ شخصيتها واضحة، عملية، ومطمئنة.
- **صوت العلامة:** مباشر وداعم؛ أمثلة: «كلمة واحدة الآن، فرق كبير لاحقًا» و«تابع ما يهمك بدون ضوضاء».
- **العلامة:** كلمة Student بجانب نقطة تقدم صغيرة، تستخدم في الشريط العلوي وعلامة التحميل.
- **اللون المميز:** Student Blue `#2458E6`.

## البنية

- `src/App.tsx`: حالة الواجهة والتنقل وتجربة الخلاصة والقصص.
- `src/data.ts`: نماذج بيانات المعاينة وروابط الصور الحقيقية.
- `src/styles.css`: الثيم، responsive layout، الحركات، ومكوّنات الصفحة.
- `src/lib/supabase.ts`: نقطة الربط المستقبلية مع Supabase دون تسريب أسرار.
- `public/manus-routes.json`: مسارات الموقع المعروفة للمعاينة والنشر.
- `app.config.ts`: هوية مشروع Webdev.

## مسار التطوير اللاحق

بعد اعتماد تجربة الخلاصة والقصص، تُضاف طبقات Supabase للمصادقة والمنشورات الحقيقية، ثم الرسائل، الترجمة وAsk AI، Oxford 5000، المتجر والمحفظة، ولوحة الإدارة. لا تُنقل أي ميزة إلى Android قبل اختبار تدفقها على الويب واعتماد شكلها.
