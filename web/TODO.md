# Student Web — نقل تطبيق Student إلى الموقع

## الحسابات والمصادقة

- [x] يستخدم الموقع نفس مشروع Supabase Auth الموجود في تطبيق Android، من دون إنشاء حسابات ثانية أو نسخ كلمات المرور.
- [x] يدعم تسجيل الدخول بالبريد وكلمة المرور وGoogle، واستعادة الجلسة وتسجيل الخروج واستعادة كلمة المرور عبر Supabase.
- [x] يقرأ ملف المستخدم نفسه من جدول `profiles`، ويحافظ على RLS وصلاحيات `student` و`teacher` و`admin`.

## الخلاصة والقصص

- [x] تُقرأ المنشورات الحقيقية من `posts` مع ملفات أصحابها من `profiles`، بحد أولي آمن قدره 20 منشورًا.
- [x] تعمل الإعجابات والتعليقات من `post_likes` و`comments` وتظهر التعليقات في لوحة سفلية مع إرسال فعلي.
- [x] تُقرأ القصص الحقيقية من `student_stories_v281` مع تجميعها حسب المالك، وتبقى إيماءات Instagram الحالية في العارض.
- [ ] يدعم الموقع إنشاء وحذف القصص ورفع الوسائط إلى Storage bucket `stories` بصلاحيات المستخدم.

## الرسائل والمجتمع

- [x] تُقرأ المحادثات وتُحمّل الرسائل وتُرسل الرسائل النصية عبر `student_get_conversations`, `student_get_messages` و`student_send_message` الموجودة في التطبيق.
- [ ] لا تُعرض بيانات مستخدم أو محادثة لا تسمح بها RLS، وتُغلق الاشتراكات اللحظية عند مغادرة الشاشة؛ الاشتراك اللحظي سيُضاف مع طبقة Realtime التالية.

## التعلم والذكاء الاصطناعي

- [x] تُقرأ المفردات من `english_vocabulary` وتُدار دفعة 20 كلمة وتقدم المستخدم عبر RPCs الحالية.
- [x] تُربط الترجمة وAsk AI بـ Edge Function `student-ai` من دون كشف مفاتيح OpenRouter أو أي مفتاح خدمة في المتصفح.
- [x] يبقى النطق المحلي في المتصفح عبر Web Speech API، مع fallback واضح عند عدم دعم المتصفح.

## المتجر والإدارة

- [x] تُقرأ المنتجات والمهام والمحفظة من نفس الجداول وRPCs المستخدمة في التطبيق.
- [x] كل مطالبة بمكافأة أو عملية شراء بالألماس تمر عبر RPC/السياسات الحالية؛ لا تُحسب الأرصدة من الواجهة.
- [ ] تُنقل لوحة الإدارة ومراقبة Ask AI مع فحص الدور من قاعدة البيانات وعدم الاعتماد على زر مخفي في الواجهة.

## التسليم

- [x] المرحلة الأولى مرت بفحص TypeScript وبناء Vite وفحص بصري لشاشة الدخول على الهاتف.
- [ ] لا يتم بناء Android أو تغيير Backend أو نشر الموقع إلا بعد اكتمال المرحلة المعنية والتحقق من عدم وجود بيانات وهمية بدل البيانات الحقيقية.
